# 영어 단어 정리

[English](README.md) · [简体中文](README.zh-CN.md) · **한국어**

Codex를 활용해 단어 목록, 손글씨 노트, 스크린샷을 깔끔하고 인쇄하기 좋은 영어·중국어 단어 학습표로 정리하는 스킬입니다.

영어 숙제, 수업 중 배운 어휘, 틀린 단어를 정리할 때 유용합니다. 단어를 보내기만 하면 표를 새로 만들거나 기존 표에 이어서 추가할 수 있습니다.

## 주요 기능

- 텍스트와 이미지에서 영어 단어, 표현, 중국어 뜻을 추출합니다.
- 흔한 철자 오류를 수정하고 빠진 뜻을 보충하면서 입력 순서를 유지합니다.
- 발음 기호, 품사, 번호를 제외하고 영어와 중국어 뜻만 두 열로 정리합니다.
- 새 문서와 탭의 이름을 자동으로 정하고, 같은 작업에서 추가 입력을 받으면 다음 빈 행에 기록합니다.
- 인쇄에 적합한 A4 양식을 사용하고 저장된 내용을 확인합니다.

## 설치

`SKILL.md`를 지원하는 Codex 환경이 필요합니다. Google Docs에 직접 저장하려면 해당 문서를 편집할 수 있는 도구를 연결해야 합니다.

이 저장소를 다운로드하거나 복제한 뒤 폴더 이름을 `vocabulary-organizer`로 유지하고 개인 Codex 스킬 폴더(일반적으로 `~/.codex/skills/`)에 넣습니다. 스킬 목록에서 선택하거나 대화에서 `$vocabulary-organizer`를 호출합니다.

## 사용 방법

```text
$vocabulary-organizer로 다음 단어를 정리해 줘.
recycle /ˌriːˈsaɪkl/ v. 回收利用
go aborad 出国
available
```

예상 결과:

| 영어 | 중국어 뜻 |
| :---: | :--- |
| recycle | 回收利用 |
| go abroad | 出国 |
| available | 可获得的、可用的 |

실제 문서는 기본 표 기능으로 두 열을 구성하며 제목 행, 발음 기호, 품사, 철자 수정 기록은 넣지 않습니다. 철자 수정 내용은 대화에서 별도로 알려 줍니다.

사진이나 스크린샷도 업로드할 수 있습니다. 같은 작업에서 단어를 계속 보내면 기존 표에 추가되며, 필요한 경우 다른 문서나 탭을 지정할 수 있습니다.

더 많은 입력 예시는 [사용 예시](examples/usage.md)를 참고하세요(중국어).

## 기본 양식

| 항목 | 설정 |
| --- | --- |
| 용지 | A4 세로, 상하좌우 여백 72 pt |
| 글꼴 | Arial, 13 pt, 굵게, 검정색 |
| 영어 열 | 가운데 정렬, 약 225.75 pt |
| 중국어 열 | 왼쪽 정렬, 약 224.25 pt |
| 표 | 검정색 0.75 pt 점선 테두리, 행 높이 약 36 pt |
| 행 수 | 페이지당 18행 |
| 셀 안쪽 여백 | 약 5 pt |

## 저장 및 개인정보

새 작업에서는 기본적으로 새 문서를 만듭니다. 이어서 작업할 때는 기존 단어를 덮어쓰지 않고 빈 행부터 채웁니다. 판독하기 어려운 손글씨는 임의로 추측하지 않고 확인을 요청합니다.

저장소에는 스킬 지침과 설명용 예시만 포함되어 있습니다. 계정 인증 정보, 개인 문서 ID, 실제 학습 기록은 포함하지 않습니다. 문서 저장에는 연결된 편집 도구의 적절한 권한이 필요합니다.
